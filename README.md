# World_Cup_Group_B_Simulator
## Overview
This project simulates the Group B stage of the FIFA World Cup using Python.The program loads team and match data from CSV file, simulates match outcomes, calculates points and standings, and predicts the final group ranking based on the provided data.
The project was developed to practice Python programming concepts such as modular design, data processing, file handling, functions, and algorithmic problem-solving.
### Features
. Load team and match data from CSV file
. Simulate World Cup group-stage matches
. Calculate points, wins, and ranking
. Generate and update group standings
. Determine final team ranking
. Modular project structure with seperate data loading and simulation components
